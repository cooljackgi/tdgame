# **App Name**: Elemental Nexus

## Core Features:

- Multiplayer Lobby: Create and join lobbies for cooperative tower defense gameplay.
- Elemental Tower Construction: Construct diverse elemental towers with unique abilities.
- Resource Management: Manage resources earned from defeating enemy waves to upgrade towers. Uses an AI tool to suggest best strategies based on the map, element availability and enemy composition
- Cooperative Gameplay: Team up online with other players to defend against AI-controlled waves.
- Tower Upgrades: Enhance tower abilities through strategic upgrades.
- Wave Progression: Defeat increasingly challenging waves of enemies.
- Visual Feedback System: Use a clear and helpful display of element type effects, and damage ranges. Generate a visual effects scheme which emphasizes clear cooperative opportunities and highlights tactical collaboration.

## Style Guidelines:

- Primary color: Vibrant light blue (#7DF9FF) representing water, for the app's prominent interactive elements.
- Background color: Dark mystical gray (#232B2B) for the map and UI backdrop, offering a high contrast environment for the colorful elemental effects.
- Accent color: Energetic yellow-orange (#FFB347) to draw attention to CTAs and areas for team cooperation.
- Body and headline font: 'Space Grotesk', a proportional sans-serif with a computerized feel that is well-suited to game-related information displays
- Design elemental icons for each tower type (fire, water, earth, air) with a consistent design language and ensure each icon reflects the core aspects of the elemental types. Water should look fluid, fire should feel dangerous etc.
- Implement a clean and intuitive layout with towers displayed prominently, with side-by-side player stats, resources, and upgrade panels for each player.
- Utilize smooth animations for tower attacks, enemy movements, and elemental effects to immerse the player and provide clear visual feedback, e.g. particle effects for explosions and splashes for water element effects.
